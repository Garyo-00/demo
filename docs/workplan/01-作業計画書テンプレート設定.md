# 01. 作業計画書テンプレート設定（/workplan-neo/templates）

> ステータス：ドラフト（デモ実装ベース）／要レビュー

## 1. 概要
- 目的：作業計画書の書式が**ゼネコン各社で異なる**ため、計画書の入力項目を自由に定義できるようにする。
- 利用ロール：**元請（ゼネコン）**。職長・作業員は利用しない（デモでは職長ロール時にメニュー非表示）。
- アクセス経路：サイドメニュー ＞ 作業計画書テンプレート設定。
- ここで作成したテンプレートを、**職長が作業計画書を新規作成する際に選択**し、選んだテンプレートに応じて入力項目が変わる。
- 対応デバイス：PC（想定）。

## 2. 画面要素

### 2-1. 一覧（`/workplan-neo/templates`）
- カード内に「作業計画書テンプレート設定一覧」、右上に **＋追加**。
- テーブル：**テンプレート名／種別／⋮（行メニュー）**。
- フッター：ページあたりの行数（**25/50/100・既定50**）、`1〜14 / 14`、前後ページ送り。
- **種別**：`マスタ` タグ（サービス標準の `【テンプレート用】〜`）。現場作成のものはタグなし。マスタは行名をグレー表示。
- ⋮メニュー：マスタ＝「内容を確認／複製」、現場作成＝「編集／複製／削除」（想定）。

### 2-2. 作成・編集（`/workplan-neo/templates/new`・`/:id`）
上から順に以下のカードで構成。

| 順 | セクション | 種類 |
|---|---|---|
| 1 | テンプレート名 | 入力 |
| 2 | 必須項目 | 固定表示（編集不可） |
| 3 | **基本情報ブロック** | ブロック |
| 4 | **機械ブロック** | ブロック |
| 5 | **積荷ブロック** | ブロック |
| 6 | **人員配置ブロック** | ブロック |
| 7 | **クレーンブロック** | ブロック |
| 8 | **調査ブロック** | ブロック |
| 9 | **厳守事項・周知事項ブロック** | ブロック |
| 10 | **その他ブロック**（仮） | ブロック（項目テーブル） |
| 11 | 書類添付 | ファイル選択 |
| 12 | チェックリスト | タブ＋項目テーブル |

- 最下部に **キャンセル／登録**。
- 作業計画書は**ブロック単位**で構成する。従来の「共通項目」「作業内容」セクションは廃止し、行き先が決まっていない項目は**その他ブロック**にまとめている（仮）。

## 3. 表示項目 / 入力項目

### 3-1. 必須項目（全テンプレート共通・編集不可）
| 項目 | 回答形式 | 必須 |
|---|---|---|
| 作業計画書名 | 自由入力 | ○（固定） |

### 3-2. ブロック
作業計画書は**ブロック単位**で構成する。テンプレートでは**使用するブロックをON/OFF**で選ぶ。
中身の詳細仕様が確定したブロック（基本情報・クレーン・その他）はブロック内に設定UIを表示し、未定のものは**使用ON/OFFのみ**設定できる。

| 順 | ブロック | 内容 | 中身の設定 |
|---|---|---|---|
| 1 | 基本情報 | 作業配置図・作業期間 | 表示のみ（編集不可）→ [3-2-1](#3-2-1-基本情報ブロック) |
| 2 | 機械 | 使用する持込機械・レンタル機械に関する項目 | ⚠️ 未定 |
| 3 | 積荷 | 積荷・吊り荷に関する項目 | ⚠️ 未定 |
| 4 | 人員配置 | 作業責任者・運転者・誘導者などの配置 | ⚠️ 未定 |
| 5 | クレーン | クレーン諸元からの自動入力 | あり → [3-2-2](#3-2-2-クレーンブロック) |
| 6 | 調査 | 地盤・架空線・埋設物などの事前調査結果 | ⚠️ 未定 |
| 7 | 厳守事項・周知事項 | 作業前に周知する厳守事項・周知事項 | ⚠️ 未定 |
| 8 | その他（仮） | 上記に当てはまらない項目 | 項目テーブル → [3-2-3](#3-2-3-その他ブロック仮) |

- [ ] ⚠️ ブロックの表示順は上表で確定して良いか。
- [ ] ⚠️ 機械／積荷／人員配置／調査／厳守事項・周知事項の各ブロックの中身（入力項目・回答形式・必須可否・出力レイアウト）。
- [ ] ⚠️ 各ブロックの中身は**固定（編集不可）**にするか、テンプレートで項目を追加できるようにするか。
- [ ] ⚠️ 従来あった「打合せ参加者サイン」ブロックは廃止した。復活の要否。
- [ ] ⚠️ 「安全指示事項」はブロックのON/OFFをやめ、**常に承認時に入力できる**扱いにした（[02](./02-安全指示事項.md)）。この前提で良いか。

#### 3-2-1. 基本情報ブロック
ブロック固有の内容のため、テンプレートでは**表示のみ（編集不可）・必須固定**。

| 項目 | 回答形式 |
|---|---|
| 作業配置図 | 図面配置（「作業配置図設定」で登録した図面上に作業範囲を配置） |
| 作業期間 | 日付範囲 |

- 作業計画書の作成画面では、このブロックの中で作業配置図（作図／アップロード）と作業期間を入力する。
- [ ] ⚠️ 基本情報ブロックをOFFにできる仕様で良いか（OFFだと作業期間が入力されない）。

#### 3-2-2. クレーンブロック
ブロックをONにすると、以下の3つの区分が表示される。

**入力項目**（職長が作業計画書で入力。ブロック固有のため**テンプレートでは編集不可**・必須固定）

| 項目 | 回答形式 |
|---|---|
| クレーンの種類 | 単一選択 |
| クレーンのメーカー | 単一選択 |
| 作業半径（m） | 数値 |
| 吊荷重量（t） | 数値 |
| フック重量（t） | 数値 |
| 吊具重量（t） | 数値 |

**自動反映**（入力項目から自動で計算・取得。**チェックボックスで使用／未使用**を選ぶ）

| 項目 | 反映元 |
|---|---|
| 定格荷重最大（m）(t) | クレーンのメーカー・種類から取得 |
| 定格荷重最小（m）(t) | クレーンのメーカー・種類から取得 |
| アウトリガー全幅張出（m） | クレーンのメーカー・種類から取得 |
| ブーム長さ最大（m） | クレーンのメーカー・種類から取得 |
| 最大作業半径（m） | クレーンのメーカー・種類から取得 |
| 最小作業半径（m） | クレーンのメーカー・種類から取得 |
| 定格総荷重 (t) | クレーンのメーカー・種類・作業半径から取得 |
| 荷重率（%） | 総荷重 ÷ 定格総荷重 × 100 |
| 判定 | 荷重率 ≦ 安全率 →「◯」／ 荷重率 ＞ 安全率 →「✕」 |

**設定**（このページで数値を設定）

| 設定 | 内容 |
|---|---|
| 安全率（％） | 判定のしきい値。テンプレートごとに設定する。 |

- [ ] ⚠️ クレーンの種類・メーカーの選択肢と諸元（定格荷重表）の持ち方（マスタの提供元・更新方法）。
- [ ] ⚠️ 総荷重＝吊荷重量＋フック重量＋吊具重量、という理解で良いか。
- [ ] ⚠️ 安全率の初期値（デモは90%）と、職長側で変更できるか。

#### 3-2-3. その他ブロック（仮）
- 従来の「共通項目」「作業内容」を**1つの項目テーブル**にまとめた仮置きのブロック。
- 列：**並べ替えハンドル／No／項目／回答形式／必須／備考／削除**。
- 操作：「5行追加」リンク、末尾の「＋」で1行追加、行のドラッグで並べ替え、ゴミ箱で削除。
- 回答形式（デモの選択肢）：自由入力／自由入力（複数行）／数値入力／日付／日付範囲／時刻／時間帯／単一選択／複数選択／チェックボックス／写真添付／ファイル添付／**持込機械選択**／**作業員選択**。
  - 単一選択・複数選択のときは**選択肢**（カンマ区切り）の入力欄が出る。
  - **持込機械選択**＝AS（安全セーフティ）に登録済みの持込機械から選ぶ形式。ここで紐づけた機械の点検QRから、この計画書が閲覧される。
- [ ] ⚠️ **「作業ごとに繰り返し入力する」概念が失われている**。従来の「作業内容」はタブで作業1・作業2…と複数持てたが、その他ブロックは1回入力のみ。繰り返し入力をどのブロックで担保するか（例：作業内容ブロックを別途設ける／各ブロックに繰り返し設定を持たせる）。
- [ ] ⚠️ その他ブロックは最終的に廃止し、全項目を各ブロックへ振り分ける想定か。

### 3-4. 書類添付
- 作業手順書など、そのテンプレートを使う計画書に**常に添付**する書類を登録（想定）。
- [ ] ⚠️ 対応拡張子・サイズ上限・件数上限。
- [ ] ⚠️ 職長が計画書作成時に**追加で**添付できるか（テンプレート添付との区別）。

### 3-5. チェックリスト
- **承認後、点検QR（機械個体）から作業計画書を閲覧する際に実施する確認項目**。
- **タブ構成**で1テンプレートに**複数**のチェックリストを持てる。タブの「＋」で追加、アクティブタブのゴミ箱で削除。
- リスト単位の項目：**チェックリスト名**／**実施者の役割**（例：運転者、玉掛け者・合図者）。
- 行の列：**並べ替えハンドル／内容／必須／備考／削除**（**回答形式は持たない**＝チェックする形式に統一）。
- [ ] ⚠️ 「実施者の役割」はマスタからの選択か自由入力か（デモは自由入力）。
- [ ] ⚠️ 複数リストがある場合、閲覧者にどう出し分けるか（役割で自動判定／作業員が選択）。
- [ ] ⚠️ 実施結果の保存・確認場所（NEO側の記録か、AS側の点検記録に紐づけるか）。

## 4. 機能・操作
| 操作 | 内容 |
|---|---|
| 追加 | 一覧の「＋追加」→ 作成画面。 |
| 編集 | 一覧の行名クリック、または ⋮＞編集。 |
| 複製 | ⋮＞複製。マスタを複製すると現場作成テンプレートになる（デモでは名称から `【テンプレート用】` を外し「（コピー）」を付与）。 |
| 削除 | ⋮＞削除（確認ダイアログ）。マスタは不可（想定）。 |
| 行追加 | 「5行追加」／末尾の「＋」。 |
| 行並べ替え | 行頭ハンドルをドラッグ。 |
| 登録 | テンプレート名必須。登録後は一覧へ戻る。 |

## 5. 状態・ロール別表示差
- 元請：全操作可。職長・作業員：メニュー非表示（デモではロール切替で再現）。
- マスタテンプレート：名称グレー＋`マスタ`タグ、編集・削除不可（想定）。

## 6. データ・外部連携
- 回答形式「持込機械選択」「作業員選択」は AS／ユーザーマスタの連携が前提（⚠️ 連携方式は未定）。
- 「基本情報」ブロックの作業配置図は「作業配置図設定」で登録した図面を参照。
- 作成されたテンプレートは、職長の作業計画書新規作成時の選択肢になる。

## 7. バリデーション・制約
- テンプレート名：必須（デモ実装済み）。
- [ ] ⚠️ テンプレート名の重複可否・文字数上限。
- [ ] ⚠️ 項目名の必須・重複チェック、項目数の上限。
- [ ] ⚠️ 選択肢の区切り（デモはカンマ区切り。区切り文字を含む選択肢の扱い）。

## 8. 例外・エッジケース
- [ ] ⚠️ **使用中テンプレートの編集**：作成済み・承認済みの計画書への影響（**スナップショット方式を推奨**。README §6.3）。
- [ ] ⚠️ 項目を削除／回答形式を変更した場合の、入力済みデータの扱い。
- [ ] ⚠️ 同一テンプレートを複数の元請ユーザーが同時に編集した場合（[02 §7](./02-安全指示事項.md) と同じ楽観ロック方式の横展開を推奨）。
