# 01. 作業計画書テンプレート設定（/workplan-neo/templates）

> ステータス：ドラフト（デモ実装ベース）／要レビュー

## 1. 概要
- 目的：作業計画書の書式が**ゼネコン各社で異なる**ため、計画書の入力項目を自由に定義できるようにする。
- 利用ロール：**元請（ゼネコン）**。職長・作業員は利用しない（デモでは職長ロール時にメニュー非表示）。
- アクセス経路：サイドメニュー ＞ 作業計画書テンプレート設定。
- ここで作成したテンプレートを、**職長が作業計画書を新規作成する際に選択**し、選んだテンプレートに応じて入力項目が変わる。
- 対応デバイス：PC（想定）。

## 2. 画面要素

### 2-1. 一覧（`/workplan-neo/templates`）
- カード内に「作業計画書テンプレート設定一覧」、右上に **＋追加**。
- テーブル：**テンプレート名／種別／⋮（行メニュー）**。
- フッター：ページあたりの行数（**25/50/100・既定50**）、`1〜14 / 14`、前後ページ送り。
- **種別**：`マスタ` タグ（サービス標準の `【テンプレート用】〜`）。現場作成のものはタグなし。マスタは行名をグレー表示。
- ⋮メニュー：マスタ＝「内容を確認／複製」、現場作成＝「編集／複製／削除」（想定）。

### 2-2. 作成・編集（`/workplan-neo/templates/new`・`/:id`）
上から順に以下のカードで構成。

| 順 | セクション | 種類 |
|---|---|---|
| 1 | テンプレート名 | 入力 |
| 2 | 必須項目 | 固定表示（編集不可） |
| 3 | **作業配置図** | 専用ブロック |
| 4 | 共通項目 | 項目テーブル |
| 5 | 作業内容 | 項目テーブル |
| 6 | **クレーンの自動入力** | 専用ブロック |
| 7 | **打合せ参加者サイン** | 専用ブロック |
| 8 | **安全指示事項** | 専用ブロック（[02](./02-安全指示事項.md)） |
| 9 | 書類添付 | ファイル選択 |
| 10 | チェックリスト | タブ＋項目テーブル |

- 最下部に **キャンセル／登録**。

## 3. 表示項目 / 入力項目

### 3-1. 必須項目（全テンプレート共通・編集不可）
| 項目 | 回答形式 | 必須 |
|---|---|---|
| 作業計画書名 | 自由入力 | ○（固定） |
| 作業期間 | 日付範囲 | ○（固定） |

### 3-2. 共通項目 / 作業内容（項目テーブル）
- 列：**並べ替えハンドル／No／項目／回答形式／必須／備考／削除**。
- 操作：「5行追加」リンク、末尾の「＋」で1行追加、行のドラッグで並べ替え、ゴミ箱で削除。
- **共通項目**＝作業計画書に1回だけ入力する項目。**作業内容**＝作業ごとに繰り返し入力する項目。
- 回答形式（デモの選択肢）：自由入力／自由入力（複数行）／数値入力／日付／日付範囲／時刻／時間帯／単一選択／複数選択／チェックボックス／写真添付／ファイル添付／**持込機械選択**／**作業員選択**。
  - 単一選択・複数選択のときは**選択肢**（カンマ区切り）の入力欄が出る。
  - **持込機械選択**＝AS（安全セーフティ）に登録済みの持込機械から選ぶ形式。ここで紐づけた機械の点検QRから、この計画書が閲覧される。

### 3-3. 専用ブロック
項目テーブルとは別に、**機能単位**で計画書に載せるまとまり。現時点は**使用ON/OFFのみ**設定でき、中身の詳細仕様は順次確定。

| ブロック | 位置 | 内容（想定） |
|---|---|---|
| 作業配置図 | 必須項目の直後 | 「作業配置図設定」で登録した図面上に、当日の作業範囲を配置する。 |
| クレーンの自動入力 | 作業内容の後 | クレーン諸元から作業半径・定格荷重などを自動入力する。 |
| 打合せ参加者サイン | 作業内容の後 | 作業前打合せの参加者がサインを記入する。 |
| 安全指示事項 | 作業内容の後 | **承認時に元請が入力**する。詳細は [02](./02-安全指示事項.md)。 |

- [ ] ⚠️ ブロックの表示順は上表で確定して良いか（現状はデモの並び）。
- [ ] ⚠️ 各ブロックの詳細仕様（入力項目・出力レイアウト・必須可否）。

### 3-4. 書類添付
- 作業手順書など、そのテンプレートを使う計画書に**常に添付**する書類を登録（想定）。
- [ ] ⚠️ 対応拡張子・サイズ上限・件数上限。
- [ ] ⚠️ 職長が計画書作成時に**追加で**添付できるか（テンプレート添付との区別）。

### 3-5. チェックリスト
- **承認後、点検QR（機械個体）から作業計画書を閲覧する際に実施する確認項目**。
- **タブ構成**で1テンプレートに**複数**のチェックリストを持てる。タブの「＋」で追加、アクティブタブのゴミ箱で削除。
- リスト単位の項目：**チェックリスト名**／**実施者の役割**（例：運転者、玉掛け者・合図者）。
- 行の列：**並べ替えハンドル／内容／必須／備考／削除**（**回答形式は持たない**＝チェックする形式に統一）。
- [ ] ⚠️ 「実施者の役割」はマスタからの選択か自由入力か（デモは自由入力）。
- [ ] ⚠️ 複数リストがある場合、閲覧者にどう出し分けるか（役割で自動判定／作業員が選択）。
- [ ] ⚠️ 実施結果の保存・確認場所（NEO側の記録か、AS側の点検記録に紐づけるか）。

## 4. 機能・操作
| 操作 | 内容 |
|---|---|
| 追加 | 一覧の「＋追加」→ 作成画面。 |
| 編集 | 一覧の行名クリック、または ⋮＞編集。 |
| 複製 | ⋮＞複製。マスタを複製すると現場作成テンプレートになる（デモでは名称から `【テンプレート用】` を外し「（コピー）」を付与）。 |
| 削除 | ⋮＞削除（確認ダイアログ）。マスタは不可（想定）。 |
| 行追加 | 「5行追加」／末尾の「＋」。 |
| 行並べ替え | 行頭ハンドルをドラッグ。 |
| 登録 | テンプレート名必須。登録後は一覧へ戻る。 |

## 5. 状態・ロール別表示差
- 元請：全操作可。職長・作業員：メニュー非表示（デモではロール切替で再現）。
- マスタテンプレート：名称グレー＋`マスタ`タグ、編集・削除不可（想定）。

## 6. データ・外部連携
- 回答形式「持込機械選択」「作業員選択」は AS／ユーザーマスタの連携が前提（⚠️ 連携方式は未定）。
- 「作業配置図」ブロックは「作業配置図設定」で登録した図面を参照。
- 作成されたテンプレートは、職長の作業計画書新規作成時の選択肢になる。

## 7. バリデーション・制約
- テンプレート名：必須（デモ実装済み）。
- [ ] ⚠️ テンプレート名の重複可否・文字数上限。
- [ ] ⚠️ 項目名の必須・重複チェック、項目数の上限。
- [ ] ⚠️ 選択肢の区切り（デモはカンマ区切り。区切り文字を含む選択肢の扱い）。

## 8. 例外・エッジケース
- [ ] ⚠️ **使用中テンプレートの編集**：作成済み・承認済みの計画書への影響（**スナップショット方式を推奨**。README §6.3）。
- [ ] ⚠️ 項目を削除／回答形式を変更した場合の、入力済みデータの扱い。
- [ ] ⚠️ 同一テンプレートを複数の元請ユーザーが同時に編集した場合（[02 §7](./02-安全指示事項.md) と同じ楽観ロック方式の横展開を推奨）。
