# 07. 資機材・ゲート登録（/workadjust/registry）

> ステータス：ドラフト（デモ実装ベース）／要レビュー

## 1. 概要
- 目的：予約対象となる資源（揚重機／ゲート／資機材・その他）を登録・管理し、予約画面への表示可否を制御する。
- 利用ロール：元請。
- アクセス経路：設定 ＞ 資機材・ゲート登録。

## 2. 画面要素
- タブ：揚重機／ゲート／資機材・その他。
- ツールバー：件数、（揚重機・資機材）持込機械から同期・一括登録・＋新規登録、（ゲート）＋ゲート登録。
- 一覧（PC＝テーブル／スマホ＝カード）。**50件ごとにページネーション**（表示件数 50/100/200）。
- モーダル：新規/編集、一括登録、持込機械から同期。

## 3. 表示項目 / 入力項目
### 揚重機
- ArchID、カテゴリ、表示名（現場内呼称）、持込会社名、一次会社、予約表示、操作。
### 資機材・その他
- ArchID、カテゴリ、表示名（現場内呼称）、持込会社名、一次会社、**予約方法（時間制／2部制・既定＝2部制）**、予約表示、操作。
### ゲート
- ゲートID、ゲート名、設置場所、備考、予約表示、操作。

## 4. 機能・操作
- 新規登録（カテゴリ・表示名・持込会社名・一次会社／すべて必須）。
- 一括登録（複数行、4項目入力の行のみ登録）。
- **持込機械から同期**（安全セーフティの持込機械一覧から選択取込）。
- **レンタル品から同期**（レンタル管理の一覧から選択取込）。※持込機械とレンタル品は**別テーブル**で管理し、それぞれのボタン・ダイアログから取り込む（揚重機／資機材・その他の両タブに設置）。
  - 同期ダイアログの表示項目は共通で、**先頭に「ArchID」列**を追加（ArchIDはそのまま取込後のArchIDとして採用）。
- 編集／削除。
- **予約表示（show）トグル**：ONの資源のみ予約画面に表示。
- **予約方法（資機材・その他のみ）**：セル内プルダウンで**時間制／2部制**を選択。**既定は2部制**。**値を変えると即時反映**（保存ボタン不要）。予約画面はこの設定に従って資機材ごとに時間制／2部制で表示（[02-予約](02-予約.md)）。「予約種類設定」タブ（[09](09-予約設定.md)）は廃止しこちらへ移設。

## 5. 状態・ロール別表示差
- 予約表示ON/OFFで予約画面の対象が決まる。

## 6. データ・外部連携
- **ArchID**：一覧の識別子（旧「ID」表記→「ArchID」に変更）。同期取込時は取込元のArchIDをそのまま採用（同一ArchIDの重複取込はしない）。
- **同期元は2系統（別テーブル）**：**持込機械**（安全セーフティ）／**レンタル品**（レンタル管理）。同期ダイアログは共通項目＋先頭にArchID列。
- **安全セーフティ（AS）連携**：
  - 「持込機械から同期」で取り込むと、以後**AS側と「同期」**する（AS側での登録との**重複判定は不要**）。
  - **更新は双方向（AS・本アプリのどちらからも可）で、後勝ち上書き**。
  - **揚重機・資機材/その他で新規登録したアイテムは、AS の openitems として扱う**（現QR予約と同じ）。openitem登録時の要件は下記。
- **AS openitems 登録要件**：
  - **登録種別はすべて「機械」**とする。
  - **表示名（現場内呼称）の値を「機械名（機種）」にも設定**する。
  - **使用期間＝登録時のプロジェクト工期の開始日〜終了日**を適用。
  - **運転者はできれば空**にしたい（ASのバリデーション要確認。可能なら**必須を解除**）。
- カテゴリ：**マスタなし**（自由記述＋サジェスト。「駐車場」等の非機械カテゴリも自由に入力可）。
- 「一次会社」「持込会社名」：**マスタなし**（自由記述＋サジェスト。協力会社設定と厳密には紐づけない）。

## 7. バリデーション・制約
- 新規/一括：カテゴリ・表示名・持込会社名・一次会社が必須。
- 表示名（現場内呼称）の**命名規則・一意性はユーザーに一任**（システムで強制しない）。
- 予約表示の初期値は**ON**（新規・一括登録・同期いずれも初期値ON）。

## 8. 例外・エッジケース
- **予約使用中の資源を非表示（予約表示OFF）にした場合**：予約画面に表示されなくなるだけで、**予約実績は残り続ける**。
- 同名の表示名（現場内呼称）重複は許容（一意性はユーザー任せ）。

## 決定事項（回答済み）
- **AS連携**：AS側登録との重複判定は不要。取込＝以後同期。更新は双方向・上書き。新規登録は AS openitems 化（登録種別「機械」／表示名を機種名にも／使用期間＝工期／運転者は空を希望）。
- **予約使用中の非表示**：表示OFFでも予約実績は保持（表示されないだけ）。
- **カテゴリ・一次会社・持込会社名**：いずれも**マスタなし**（自由記述）。
- **表示名**：命名規則・一意性はユーザー一任。
- **ArchID**：旧「ID」列を「ArchID」表記に変更（デモ反映済み）。
- **予約表示の初期値**：新規・大量登録とも**ON**。

### ゲートと資機材/その他の項目・扱いの違い（確定）
| 観点 | ゲート | 資機材・その他（揚重機含む） |
|---|---|---|
| 登録項目 | ゲート名・設置場所・備考 | カテゴリ・表示名・持込会社名・一次会社・**予約方法** |
| 予約方法 | **時間制固定** | **時間制／2部制を選択**（既定2部制） |
| 予約フォーム | **車種**の入力あり | 車種なし |
| 出力帳票 | ゲート予約表（車種列あり） | 資機材予約表（車種列なし） |
| AS openitems 化 | **対象外（確定）** | **対象**（新規登録を機械としてopenitem化） |
