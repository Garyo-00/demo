# 03. 配置図作成（/workadjust/floor-plan）

> ステータス：ドラフト（デモ実装ベース）／要レビュー

## 1. 概要
- 目的：作業日ごとに、台紙（平面図）上へスタンプ（重機・車両／作業員・区画等）を配置して現場の配置図を作成・編集し、印刷する。あわせて元請連絡事項を記入。
- 利用ロール：元請、職長は閲覧不可とする。
- アクセス経路：サイドバー「配置図作成」。

## 2. 画面要素（動線）
1. **初期表示**：平面図プルダウンのみ（選択肢＝「作業配置図設定」に登録された図面すべて）。未選択時は「平面図を選択してください」。
2. **平面図を選択**すると、当日のその平面図の**配置図の作成状況をバッジ表示**：
   - **未作成**（赤バッジ）：「前日からコピー」「＋新規作成」ボタン。
   - **作成済**（緑バッジ）：「編集」「削除」「出力」ボタン＋**プレビュー**。
3. **作成／編集ダイアログ**（全画面レイアウト。スタンプ配置はここでのみ可能）：
   - ヘッダー：平面図プルダウン、元に戻す／やり直し（undo/redo）、保存、×閉じる。
   - 左：**台紙キャンバス**（ドット方眼＋平面図画像）／左下に**ズーム（＋／－／全体表示）**。
   - 右：**スタンプパレット**（グループ：重機・車両／作業員・区画）。
4. **プレビュー**（作成済みのみ・**編集不可**）：台紙画像＋配置済みスタンプの閲覧表示。
5. **元請連絡事項**：配置図が作成済みのときのみ表示。

## 3. 表示項目 / 入力項目
- 平面図（台紙）：作業配置図設定の登録図面から選択。
- 配置図の状態：本日の作成状況（未作成／作成済）。
- スタンプ（配置マーカー）：種類（名称・アイコン・色）、位置（X%/Y%）。
- 元請連絡事項：日付ごとのフリーテキスト。

## 4. 機能・操作
- **新規作成**：選択中の平面図でダイアログを開き、空の台紙にスタンプを配置。
- **編集**：作成済み配置図をダイアログで開き、スタンプを追加・移動・削除。
- **スタンプ操作**（ダイアログ内のみ）：
  - パレットのスタンプを**クリックで台紙に配置**。
  - 配置後は**ドラッグ＆ドロップで移動**。ホバーで出る×で削除。
  - **元に戻す／やり直し**（undo/redo）、**ズーム**（0.5〜2倍／全体表示）。
- **保存**：ダイアログを閉じてプレビューに反映。**キャンセル**は破棄。
- **前日からコピー**：前日の同一平面図の配置図（配置）＋連絡事項を当日へ複製。
- **削除**：当日のその平面図の配置図を削除（確認あり）。
- **出力**：`window.print` で**配置図（図面＋スタンプ）と元請連絡事項**を印刷（A4縦・デモレイアウト）。
- **元請連絡事項**：鉛筆アイコンで編集モード→テキスト編集→保存（上書き）／キャンセル。

## 5. 状態・ロール別表示差
- 本日の配置図：未作成（赤バッジ）／作成済（緑バッジ）でボタン群を出し分け。
- **プレビュー上ではスタンプを変更できない**（追加・移動・削除は「編集」または「新規作成」ダイアログのみ）。
- 職長は非表示。

## 6. データ・外部連携
- 台紙（平面図）：作業配置図設定（NEOと共通）。
- スタンプ種類：現状はデモ用の固定リスト（重機17種＋作業員・区画6種）。アイコンは絵文字＋色枠で代替。本番はNEOのスタンプ種類を流用する。

## 7. バリデーション・制約
- 平面図が未選択のうちは作成・編集不可。
- 台紙が未登録のときは作業配置図設定での登録が前提（プルダウンに選択肢が表示されない）。
- 閲覧・編集は**元請ユーザーのみ**（職長・作業員は不可）。
- **元請連絡事項の編集中に離脱する場合は警告**（実装済み）：
  - ブラウザ操作（リロード/タブを閉じる）は `beforeunload` で警告。
  - **アプリ内遷移（サイドバーのメニュー／ブランド／戻る、および日付送り）も確認ダイアログでブロック**。
- **元請連絡事項は最終更新者・更新時刻を表示**し、保存は**楽観的ロック**（編集開始時の版と保存時の版を突合。他者が先に更新していれば上書きせず「再読込」を促す）。

## 印刷（出力）仕様
- **A4縦を既定**（名前付きページ `@page fpPortrait` で指定。他帳票の横向きには非干渉）。**押印欄なし**。
- ヘッダーは**作業予定の印刷プレビューを踏襲**（工事番号／工事名称／タイトル「作業配置図」／対象日・平面図名）。
- 用途：**PDF保存・掲示**の両方を想定。

## 8. 例外・エッジケース
- 平面図にスタンプが未登録の台紙でも保存可能にする。
- 前日に同一平面図の配置図が無い場合のコピーはコピーボタンを非アクティブにする。
- 使用中（作成済み）の配置図の削除。

## 決定事項（回答済み）
- **スタンプのマスタ**：本番は**NEOのスタンプ種類を流用**。デモは現仕様（絵文字＋色枠の23種）でOK。
- **スタンプの保持情報／予約・作業予定連動**：**不要**（独立した機能として柔軟性を持たせる）。
- **座標系・ズーム/パン/回転/重なり順**：本番は**NEOに合わせる**。デモは現仕様でOK。
- **保存・確定・版管理**：確定ボタンは無いため確定の定義は不要。**版管理・履歴は不要**。
- **同時編集の排他**：**最終更新者・更新時刻の表示＋楽観的ロック**を採用（§7）。
- **台紙（作業配置図設定）を削除・改訂した場合**：**保存済み（作成済み）の配置図はそのまま残る**。編集しても**保存時点の台紙（スナップショット）で扱う**（配置図は作成時に台紙の名称・画像を取り込むため、台紙削除後も影響しない）。詳細は[06-作業配置図設定](06-作業配置図設定.md)。
- **出力レイアウト**：A4縦を既定・押印なし・ヘッダーは作業予定の印刷プレビュー踏襲（§印刷仕様）。PDF保存/掲示の両方。
- **閲覧・編集権限**：**元請ユーザーのみ**。
- **元請連絡事項**：周知先・通知は不要。**印刷／現場サイネージへの投影（元請が投影）**のみ想定。
- **日付切替/離脱時の未保存編集**：元請連絡事項の編集中の離脱は警告する（§7）。
