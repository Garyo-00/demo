# 00. 共通レイアウト（サイドバー / ヘッダー / 日付送り / ロール / 通知）

> ステータス：ドラフト（デモ実装ベース）／要レビュー

## 1. 概要
- 目的：全画面共通のナビゲーション・ヘッダー・ロール切替・ページ内でアラートを提供。
- 利用ロール：元請／職長（表示差あり・想定）。
- 対応デバイス：PC／スマホ（スマホはサイドバーをドロワー化）。

## 2. 画面要素
- **サイドバー**：ブランド（作業間調整pro／現場名）、メニュー（作業予定一覧／予約／配置図作成／作業実績入力用QR発行／設定[アコーディオン]）、外部リンク（安全セーフティ／出面・日報管理／KY NEXT／作業計画書NEO）、「デモ画面一覧へ戻る」。
- **設定アコーディオン**：作業配置図設定／資機材・ゲート登録／協力会社設定／予約設定。
- **ヘッダー**：通知ベル、日付送り。ロール切替は本番では表示させない。
- **スマホ**：ハンバーガーでドロワー表示。ハンバーガー右に現場名（プロジェクト名）を表示。
- **全体レイアウト**：グレー背景（#F2F5F9）の上に、各画面のコンテンツを1枚の白いカードで表示。

## 3. 表示項目
- 現場名（想定：ログインユーザーの所属現場）。
- サイドメニューはロールで出し分け。（元請=管理者、一般、JV構成員/協力会社=協力会社）

## 4. 機能・操作
- メニュー選択で画面遷移。外部リンクは別タブ。
- **ロール切替（元請/職長）**：デモ用トグル。本番は認証で自動判定。
- **通知ベル**：予約の重複（通常予約が同一資源・時間帯で重複）を件数バッジ＋一覧で表示。**重複している会社を優劣なく列挙**（各社の予約時間＋重複時間帯）。**3社以上のバッティングにも対応**。表示中の作業日が対象、スポット予約は対象外。
- **日付送り（前日/翌日/日付ピッカー）**：全画面共通の「作業日」を変更。**「予約」「作業予定一覧」「配置図作成」以外のページでは非アクティブ（グレーアウト）**。**初期値は翌日（明日）の日付**とする。

## 5. 状態・ロール別表示差
- 職長では「配置図作成」「作業実績入力用QR発行」「設定」「通知ベル」を非表示。
- **スマホドロワーの職長/元請の表示差はPC表示と同じ**（同一のロール別メニュー出し分け・通知ベルの表示可否をそのまま適用）。
- ロールはブラウザに保持（localStorage）だが、本番は認証セッション。

## 6. 外部サイトリンク
- 外部リンク先は関連サービス（安全セーフティ/出面日報/KY NEXT/NEO）は現状プレースホルダー。

## 7. バリデーション・制約
- 日付送りは有効な日付のみ。
