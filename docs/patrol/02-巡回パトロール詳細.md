# 02. 巡回パトロール詳細（`/patrol/records/:id`）

> ステータス：ドラフト／要レビュー
> 本番で想定される仕様を記載する。デモ固有の挙動は [README §6](./README.md#6-本仕様と画面デモの差異明記) を参照。

## 1. 概要
- 目的：巡回記録の内容を確認し、**元請確認**と**是正入力**を行う。
- 利用ロール：元請／協力会社。
- アクセス経路：[01 一覧](./01-巡回パトロール一覧.md)の「詳細」ボタン。
- 対応デバイス：PC を主、スマホ・タブレットでも操作可（是正入力・追記は現場から行う想定）。

### この画面の中心となる業務ルール
| ルール | 内容 |
|---|---|
| R-1 | **作業所コメント（元請確認コメント）は必須**。未入力では元請確認を完了できない。 |
| R-2 | **元請確認の実施後、作業所コメントは編集できない**。 |
| R-3 | **是正内容の入力は任意**。元請確認時に未入力でも確認を完了できる。 |
| R-4 | **元請確認後、是正入力はいつでも何度でも可能**。 |
| R-5 | 巡回記録そのもの（チェック項目の回答・所見・巡回時の写真）は、**この画面からは編集しない**。作成はQR経由のみ。 |

## 2. 画面要素
上から順に：
1. 一覧へ戻る導線／ステータス表示。
2. 基本情報ブロック（§3.1）。
3. 状態に応じた案内（§5）。
4. 巡回項目（§3.2）。
5. ヒアリング・所見。
6. 写真（§3.3）。
7. 作業所コメント（§3.4）。
8. 追記（[03](./03-追記.md)）。
9. アクション：印刷（左）／状態に応じた主ボタン（右）。

## 3. 表示項目 / 入力項目

### 3.1 基本情報（読み取り専用）
| 項目 | 内容 |
|---|---|
| 巡回記録No. | 記録の識別番号 |
| 実施日 | 巡回を実施した日 |
| 現場名 | 対象の現場（工事名） |
| 実施会社 | 巡回を実施した会社 |
| 一次会社 | 実施会社の一次請 |
| 実施者 | 実施した担当者 |
| 同行会社・名前 | 巡回に同行した会社・担当者 |
| 元請確認日 | 元請確認を完了した日（未確認は空） |
| 元請確認者 | 元請確認を行ったユーザー（未確認は空） |

- 巡回記録No.の**採番規則はエンジニアマター**（決定事項 D-29）。実装側で決定し、決めた規則を本書に反映すること。
- 元請確認日を**日付のみとするか日時まで保持するかはエンジニアマター**（決定事項 D-30）。監査を考えると日時を推奨。

### 3.2 巡回項目
現場ごとに設定されたチェック項目に対する回答を、**登録順の連番付き**で表示する。

| 項目 | 内容 | 編集 |
|---|---|---|
| 項目文 | チェック項目の本文 | 不可 |
| 評価 | **現場ごとに設定された選択肢**から巡回時に選択（例：危険／要是正／普通） | 不可（巡回時に確定） |
| コメント | 巡回実施者が入力した指摘・メモ | 不可 |
| **是正内容** | 指摘に対する是正の記載 | **可（§4.2）** |

- **評価の選択肢はユーザーが設定できる**（決定事項 D-16）。選択肢を実装に固定で持たせないこと。**評価値に依存した分岐を作らない**。
  - 設定画面の仕様は別途提示される。
- **是正内容の入力欄は、評価にかかわらずすべての項目に表示する**（決定事項 D-15）。
- 既に是正内容が登録されている項目は、編集中でなくても内容を表示する。

### 3.3 写真
巡回時の指摘写真と、その是正結果を**左右1組**で対応付けて表示する。

| 位置 | 内容 | 編集 |
|---|---|---|
| 左 | 巡回時に撮影した写真＋キャプション（指摘内容） | 不可 |
| 右 | **是正写真**（未添付時は「写真を添付」）＋**コメント** | 可（§4.2） |

- 是正写真は添付後に差し替え・削除ができる。
- **是正写真は1組につき1枚のみ**（決定事項 D-31）。複数枚は添付できない。
- 写真は**記録単位のリストとして保持し、チェック項目には紐づけない**（決定事項 D-5）。どの指摘に対応する写真かはキャプションで表現する。
- 画像の保存・サイズ・EXIF の扱いは**エンジニアマター**（[README D-79](./README.md)）。

### 3.4 作業所コメント（元請確認コメント）
| 状態 | 表示 |
|---|---|
| 元請確認前（元請ユーザー） | 入力欄（**必須**）。「元請確認後は編集できません」の注記を添える |
| 元請確認前（協力会社） | 「未入力」と表示（入力不可） |
| 元請確認後（全ロール） | **テキスト表示のみ。編集手段を提供しない**（R-2） |

## 4. 機能・操作

### 4.1 元請確認
- 実行できるロール：**元請のみ**。
- 実行できる状態：元請確認が未実施の記録のみ。
- 操作：「元請確認済みにする」ボタン。
- 実行時に保存する内容：
  - 作業所コメント（必須）
  - 入力済みの是正内容・是正写真・是正コメント（任意）
  - **元請確認日・元請確認者**（サーバ時刻・認証ユーザー）
- バリデーション：作業所コメントが空（空白のみを含む）の場合はエラーを表示し、確認を完了させない。
- 完了後：ステータスが「元請確認済み」に変わり、作業所コメントは編集不可になる。

- **元請確認の取り消し・差し戻しはできない**（決定事項 D-13）。一度確認したら未確認には戻せず、作業所コメントも再編集できない（R-2）。
- 元請確認の完了を**通知しない**（決定事項 D-18）。

### 4.2 是正入力
- 実行できるロール：**元請のみ**（決定事項 D-14）。元請確認の前後を問わず、**協力会社は是正入力できない**。
  - 業務上も是正を記載するのは元請であるため。協力会社が実施後に情報を残す場合は追記（[03](./03-追記.md)）を用いる。
  - 元請確認**前**：元請確認の操作に含まれる形で入力する
  - 元請確認**後**：「是正入力」から何度でも更新する
- 実行できる回数：**制限なし。いつでも何度でも**（R-4）。
- 対象：**すべての項目**の是正内容と、写真の是正欄（是正写真／是正コメント）。
- 操作：「是正入力」ボタンで編集モードに入り、「是正内容を保存」で確定、「キャンセル」で破棄する。
- **作業所コメントは是正入力の対象外**（R-2）。

- 保存方式は**上書き保存**とし、**変更履歴は保持しない**（決定事項 D-3）。最新の是正内容のみを保持する。
- 是正入力の**実施者・実施日時は記録しない**（決定事項 D-4）。追記（[03](./03-追記.md)）とは異なり、誰がいつ是正したかは残らない。経緯を残したい場合は追記を用いる運用とする。

### 4.3 印刷
巡回記録を帳票として印刷する。**画面のレイアウトをそのまま印刷するのではなく、専用の印刷レイアウトを用いる**。

#### 用紙・出力
- **A4縦**。内容量に応じて複数ページになる。
- 入力欄・操作ボタン・画面内の案内・ナビゲーションは印刷対象外。**保存済みの内容をテキストとして出力する**。
- 項目・写真・追記の各ブロックはページ途中で分断しない（`break-inside: avoid` 相当）。

#### 構成（上から順）
| # | ブロック | 内容 |
|---|---|---|
| 1 | 基本情報 | 3行×3組の枠付き表。巡回記録No./実施日/現場名、実施会社/一次会社/実施者、同行会社・名前/元請確認日/元請確認者。ラベルは太字 |
| 2 | 巡回項目 | 1項目1枠。左から連番・項目文、**右端に評価を枠囲みで表示**。下に「コメント」、是正内容があれば「是正内容」 |
| 3 | ヒアリング・所見 | 中央寄せの帯見出し＋本文 |
| 4 | 写真 | 帯見出し＋1組ごとに左右2枠。左＝巡回時の写真とキャプション、右＝是正写真（未添付なら空枠）とキャプション「是正」 |
| 5 | 作業所コメント | 帯見出し＋本文 |
| 6 | **追記** | 帯見出し＋追記1件ごとに枠。**登録者（ロール）・登録日時（更新があれば更新日時）・本文・添付ファイル**。添付画像はサムネイル、画像以外はファイル名とサイズ（決定事項 D-12） |

- 追記が0件の場合も見出しは出す（空欄）。
- 論理削除された追記は出力しない（[03 D-9](./03-追記.md)）。
- **印刷枚数・添付画像の表示枚数に上限は設けない**（決定事項 D-17）。内容が多い場合は枚数が増えるだけとする。

## 5. 状態・ロール別表示差

| 状態 × ロール | 是正欄 | 作業所コメント | 主ボタン | 案内表示 |
|---|---|---|---|---|
| 巡回済み × 元請 | 入力可 | 入力欄（必須） | 元請確認済みにする | — |
| 巡回済み × 協力会社 | **表示のみ（入力不可）** | 「未入力」 | なし | 元請確認待ち・是正は元請が行う旨 |
| 元請確認済み × 元請 | 「是正入力」で編集可 | 表示のみ | 是正入力 | 確認済み・コメント編集不可・是正は随時可である旨 |
| 元請確認済み × 協力会社 | **表示のみ（入力不可）** | 表示のみ | **なし** | 確認済み・是正入力は元請のみ である旨 |

## 6. データ・外部連携
- 巡回記録は現場に属し、チェック項目は現場のチェック項目マスタに基づく。
- 添付画像はオブジェクトストレージに保存し、権限付きURLで配信する（[README §5.4](./README.md)）。
- チェック項目マスタ・評価の選択肢の**設定画面は後日作成**する（決定事項 D-32）。仕様は別途提示される。

## 7. バリデーション・制約
| 対象 | ルール |
|---|---|
| 作業所コメント | 必須（空白のみ不可）。元請確認時に検証。確認後は更新不可（**サーバ側でも保証**） |
| 是正内容 | 任意。文字数上限は要確定 |
| 是正写真 | 画像形式・最大サイズ・枚数は要確定（[README §5.4](./README.md)） |
| 元請確認 | 元請ロールのみ。未確認の記録のみ。**取り消し不可** |
| 是正入力 | **元請ロールのみ**（確認の前後を問わず） |

- 各テキストの**文字数上限はエンジニアマター**（決定事項 D-33）。実装側で決定し本書に反映すること。

## 8. 例外・エッジケース
- 存在しない／権限スコープ外の記録IDを直接指定 → 404／403 相当。
- 元請確認の**二重実行**（複数の元請が同時に確認）→ サーバ側で先勝ちにし、後続はエラーとして現在の状態を返す。
- 是正入力中に他ユーザーが同じ記録を更新 → 上書き競合（[README §5.3](./README.md)）。
- 添付画像のアップロード失敗・通信断（現場のスマホ利用を想定）。
- 巡回時の写真が0枚の記録（写真セクション自体を表示しない）。

## 決定事項（回答済み）
- **D-3 是正内容は上書き保存**。変更履歴は保持しない（§4.2）。
- **D-4 是正入力の実施者・実施日時は記録しない**（§4.2）。追記機能と非対称になるが、是正は記録の一部として扱い、実施者の追跡は求めない。
- **D-5 写真はチェック項目に紐づけない**（§3.3）。記録単位の写真リストとして保持する。
- **D-12 印刷帳票に追記を含める**（§4.3）。帳票の構成は §4.3 の表のとおり。
- **D-13 元請確認の取り消し・差し戻しはできない**（§4.1）。
- **D-14 是正入力は元請のみ**（§4.2）。協力会社は元請確認の前後を問わず是正できない。業務上も是正するのは元請。
- **D-15 是正内容の入力欄はすべての項目に表示する**（§3.2）。評価による出し分けはしない。
- **D-16 評価の選択肢はユーザーが現場ごとに設定する**（§3.2）。実装に固定の選択肢を持たせず、評価値に依存した分岐を作らない。設定画面の仕様は別途。
- **D-17 印刷の枚数・画像表示枚数に上限を設けない**（§4.3）。
- **D-18 通知は行わない**（§4.1）。
- **D-29 巡回記録No.の採番規則はエンジニアマター**（§3.1）。
- **D-30 元請確認日を日付のみ／日時のどちらで保持するかはエンジニアマター**（§3.1）。
- **D-31 是正写真は1組につき1枚のみ**（§3.3）。
- **D-32 チェック項目マスタ・評価の選択肢の設定画面は後日作成**（§6）。
- **D-33 各テキストの文字数上限はエンジニアマター**（§7）。
